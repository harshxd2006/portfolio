# harsh.ai — Portfolio

Personal portfolio for Harsh — B.Tech Engineering Physics at NIT Hamirpur. Built with React, Vite, Tailwind CSS, Three.js, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

Upload the `dist` folder to Vercel, Netlify, or GitHub Pages.
